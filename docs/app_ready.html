Export for GitHub Pages

Use this mode if you want to publish the generated frontend on your own GitHub Pages site. The frontend can still use the secure Djungo proxy on builder.sgbh.org.

Download index.html Download viewer.html Download codice.gs

After downloading the files, upload index.html and viewer.html to your GitHub Pages repository. Then deploy codice.gs as an Apps Script Web App and register the backend connection using the hosted connection section.

Djungo principle

The generated app remains portable: the code is readable, the data stays in your spreadsheet, and the browser does not expose the Apps Script URL or write key.
